1. Summary
A scheduled reindex job on search-index ran concurrently with an unrelated bulk-import job, causing query latency to climb for roughly 40 minutes before the reindex completed and latency self-recovered.
2. Impact
Internal search latency (used by several engineering tools, not customer-facing) roughly tripled for 40 minutes; no customer-facing impact.
3. Root cause
The reindex scheduler had no mutual-exclusion check against other bulk jobs touching the same index. Once the reindex job completed, index read latency returned to baseline without any manual intervention.
4. Root cause summary
Root cause category
Scheduling gap -- no mutual exclusion between reindex and bulk-import jobs.
